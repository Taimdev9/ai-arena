# 🤖 Lab Bot

لعبة 2D فيها AI يتعلم يلعب من الصفر بواسطة **Q-Learning**.

## 🎮 كيف تلعب

افتح الرابط:
`https://Taimdev9.github.io/lab-bot/`


## 🧠 كيف يتعلم AI

- AI يبدأ بأصفار تماماً — ما يعرف شي عن اللعبة.
- يلعب، يغلط، يجرب، يتعلم من المكافآت والعقوبات.
- كل حلقة (Episode) يتحسن شوي.
- الاستكشاف (Epsilon) ينخفض تدريجياً من 1.00 إلى 0.05.

## ✨ الميزات

- تدريب ذاتي مستمر بدون تدخل
- حفظ تلقائي في المتصفح (localStorage)
- عرض مباشر: عدد الحلقات، الفوز، النسبة، الوقت، الاستكشاف
- رسم حي بالـ Canvas
- زر مشاهدة AI بعد التدريب

## 📊 الأداء المتوقع

| وقت التدريب | نسبة النجاح |
|-------------|-------------|
| 1 دقيقة     | ~20%        |
| 5 دقائق     | ~70%        |
| 15 دقيقة    | ~95%        |

> النتائج تختلف حسب سرعة الجهاز.

## 🛠️ التقنيات

- HTML5 / CSS3 / JavaScript (Vanilla)
- Canvas 2D للرسم
- Q-Learning (Reinforcement Learning)
- localStorage للحفظ

## 🚀 التشغيل محلياً

ما تحتاج أي تثبيت:

1. حمّل الملفات الثلاثة.
2. افتح `index.html` بأي متصفح.
3. اضغط "ابدأ التدريب الذاتي".
