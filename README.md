# 🎮 AI Arena

الرابط الرئيسي: [https://Taimdev9.github.io/ai-arena/](https://Taimdev9.github.io/ai-arena/)

## 🕹️ الألعاب

### 🤖 Lab Bot

روبوت يتعلم يوصّل الهدف في مختبر مليان جدران وعوائق، بواسطة **Q-Learning**.

- 🔗 **العب:** [https://Taimdev9.github.io/ai-arena/lab-bot/](https://Taimdev9.github.io/ai-arena/lab-bot/)
- 🧠 **كيف يتعلم:**
  - يبدأ بأصفار تماماً — ما يعرف شي.
  - يلعب، يغلط، يجرب، يتعلم من المكافآت والعقوبات.
  - كل حلقة (Episode) يتحسن شوي.
  - الاستكشاف (Epsilon) ينخفض تدريجياً من 1.00 إلى 0.05.
- ✨ **الميزات:**
  - تدريب ذاتي مستمر
  - حفظ محلي (localStorage)
  - حفظ سحابي (Firebase Firestore)
  - إحصاءات مباشرة (حلقات، فوز، نسبة، وقت، استكشاف)

### 🏎️ AI Racing

سيارة تتعلم تقود على مضمار، ويتنافس فيها البشر ضد AIs.

- 🔗 **العب:** قيد الإنشاء
- 🚧 **قيد التطوير:**
  - [x] مضمار + سيارة تتحكم فيها يدوياً
  - [ ] حساسات للسيارة (Sensors)
  - [ ] AI يتعلم يقود
  - [ ] Leaderboard عالمي (أفضل بشر vs أفضل AIs)
